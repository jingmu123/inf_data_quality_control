## reclean1_drug_detail_zh

### 1.特殊符号删除

例如：



C16H20N2O4S2?2HCl?H2O，分子量：459.40。（里面的问号是无关的符号）

增加删除1：

```
[r'([┣\?？]|4&nbs)',r'删除1:<u>\1</u>'],
```

### 2.无关文本

例如：

和心律失常，心脏传导阻滞，浓度进一步升高，可使心跳停止。3连续使用硫酸镁可引起便秘，部分病人可出现麻痹性肠梗阻，停药后好转。4&nbs

增加删除1：

```
[r'([┣\?？]|4&nbs)',r'删除1:<u>\1</u>'],
```

### 3.多余换行

初次清洗对序号内容增加换行时导致了出现部分的多余换行，调整增加换行为

```
[R'([^\n0-9A-Za-z@\(（\-\u4e00-\u9fa5] ?)(\d+[．.、][^0-9%].*)',R'\1\n\2'],
```
