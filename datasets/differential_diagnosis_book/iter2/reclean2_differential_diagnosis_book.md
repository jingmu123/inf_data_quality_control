14.删除重复语句

例如：

#第5版前言

第5版前言

除了格式上会有一些符号不一样，但是内容是一样的，通过函数删除重复的标题，增加删除重复语句

```
def rm_lid_piece(self, context):  # 删除重复语句
    end_index = len(context)
    same_lis = []
    for index, part in enumerate(context):
        if index + 1 == end_index:
            break

        if not re.sub(r'\s', '', part) or not re.sub(r'\s', '', context[index + 1]):
            continue

        part=re.sub('(#|\/|\s|　|=)','',part)
        part2=re.sub('(#|\/|\s|　|=)', '', context[index + 1])

        if part == part2:
            context[index] = '删除重复语句：<u>'+context[index]+'</u>'

    return context
```
