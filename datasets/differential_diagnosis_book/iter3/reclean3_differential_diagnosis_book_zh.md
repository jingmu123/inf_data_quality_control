### 1.无关数字与多余符号的补充（单独一行出现）

例如：

134

· _·_

(C) (D)

补充到删除10：

```
[r'(\n|^)(\**[A-Za-z ·_0-9（）()]+\**)(\n|$)',r'\1删除10:<u>\2</u>\3'],
```

### 2.人名删除的补充

例如：

(冯晓源 王 满)

两个字的人名偶尔会出现中间用空格等字符填充的情况，补充到删除2：

```
    [r'(\n|^)( *[(（{][\u4e00-\u9fa5][ _]{0,2}[\u4e00-\u9fa5 ]{1,2}(?:[　 ][\u4e00-\u9fa5 ]{2,3})*[）)][ _]*)(\n|$)',r'\1删除2:<u>\2</u>\3'],#人名，改
```

### 3.删除多余的左括号或右括号

例如：

Gd-DTPA增强：增强MRI检查对诊断血管母细胞瘤有重要的价值。囊肿不增强，囊壁可增强也可不强化。但壁结节几乎全部明显增强。强化均匀(图8-18)。因为平扫 MRI 可能不易发现壁结节而造成误诊，所以对怀疑血管母细胞瘤者必须进行增强 MRI 检查。实质性的血管母细胞瘤多数明显增强，强化均匀)（左边这个右括号是多余的）。

这类无关文本除去本身句子里自带的括号内容外（例如：(图8-18)），存在多余的部分（左括号or右括号），现在增加删除：

```
[r'((?:\n|^)[^\n\(\)（）]*)([^\n\(\)（）]*[\(（][^\n\(\)（）]*[）\)][^\n\(\)（）]*)([()（）])([^\n\(\)（）]*(?:\n|$))',r'\1\2\4'],
```

### 4.错误删除调整

例如：

......一般不难诊断。（错误开始删除位置）在影像学上主要是根据空洞病变的大小、空洞的厚度、空洞内外缘的表现、洞内及周围的异常形态等作出鉴别诊断；（正确开始删除的位置）常见的肺癌、结核及肺脓肿在影像学上的区别见表17-1。

增加截止符号；，错误删除了以句号为截止符后的部分正文，现在调整到删除8：

```
[r'([^\n(（。，；]*(?:参?见|参考)[图表第]\d+[\–\-\—.]\d+[^\n）)。]*。)',r'删除8:<u>\1</u>'],
```

### 5.缺少符号

例如：

【诊断方法

这类小标题会出现缺少右中括号的情况，增加补充符号1：

```
[r'(\n|^)(【[^\n】\\\]\} ]*)(\\\]|\})?(\n|$)',r'\1\2补充符号1：】\4'],
```

### 6.参考文献的补充

部分参考文献因为缺字或多余换行问题会导致格式匹配不上，现在只要在关键字下面出现序号或者年份之一就满足条件，并且补充几个个例，补充到删除3：

```
[r'(\n|^)((?:# *第[0-9一-十]+章.*参考文献\n*|参考文献(?:\n-+)?)+((?:\n+[*_]*\d+[.,，、\\]?.*)|(?:\n+.*\d{4}.*)|(?:\n+第[0-9一-十四]+[章节].*)|(?:\n+(少尿或无尿|多　尿|血 尿|血红蛋白尿|脓 尿|乳 糜 尿)))+)',r'\1删除3:<u>\2</u>'],#改
```

### 13.个例的图表格索引类的删除

例如:

### 15.多余换行

#### 15.1补充了上一段文本可以是序号开头的内容，例如：

(5)医源性所致，如注射胰岛素过量、注射胰岛

（ 多余换行 ）素后未进食等。

#### 15.2补充链接字符可以是英文与数字，补充连接符，\-\_、·~

上述改动补充到删除换行1：

```
[r'(\n|^)((?:[(（][▲0-9][）)])?[^\n#(（删图表第见一二三四五六七八九十].*[\u4e00-\u9fa5A-Za-z③0-9~] *[，\-\_、·]? *)(\n+)((?:删除\d+:<u>.*\n+|第[一-十四0-9]+.*\n+)*)( *[，\-\_\\]? *(?:[(（][▲][）)])?[^\n_（(#【<删图表第一二三四五六七八九十].*)',r'\1\2 删除换行1: \5\n\4'],
```
