## reclean5_differential_diagnosis_book_zh

### 1.缺少标点

例如：

MRI 征象】

病理】

增加补充符号2：

```
[r'(\n|^)(\\\[)?([^\n【]*】)(\n|$)',r'\1补充符号3：【\3\4'],
```

### 2.多余换行补充

例如：

表现为脑池内及脑沟内有明显T高信号血液，并可在脑回表面形成沉着，表现为T加权像脑回表面的高信号(图5-1)，T加权像表现不明显，用磁敏感序列成像，可见出血

部位的含铁血黄素沉着

主要因为上一段的字符是表，误判断为是表格索引，补充这一类到删除换行1：

```
[r'(\n|^)((?:[(（][▲0-9^]+[）)])?(?:[^\n#(（删图表第见一二三四五六七八九十]|一般|表[现面]).*(?:[\u4e00-\u9fa5A-Za-z③0-9~]|[^u]>) *[，\-\_、·]? *)(\n+)((?:删除\d+:<u>.*\n+|第[一-十四0-9]+.*\n+)*)( *[，\-\_\\]? *(?:[(（][▲][）)])?(?:(?:[^\n_（(#【<删图表第一二三四五六七八九十0-9]|图像中)|(?:\d+[^.0-9])|(?:\d+\.\d+[%+\-×/])|(?:[(（].{5,}[）)])|(?:0\.)).*)',r'\1\2 删除换行1: \5\n\4'],#改
```

### 3.无关链接补充

例如：

#titlepage.xhtml

补充到删除1：

```
[r'(\n|^)(#? *text\/[A-Za-z0-9]+[.]html *|#? *[a-zA-Z]+\.xhtml| *未知 *| *PDG *| *[(（]?续表[）)]? *)',r'\1删除1:<u>\2</u>'],
```

### 4.括号内参考内容补充

例如：

(请见参考书目5，19)

补充到删除6：

```
[r'([（(]+ *(?:[参详][见考][^\n()（）]*[章节] *|[^\n()（）]*参[见考](?:上文|本章|书目).*|[选引]自[^\n()（）]*|图示[^\n()（）]*|[见续]?[图表]\d+[\–\-\—.]\d+[^\n()（）]*|[^\n()（）]*\d{4}[，,;；：:][^\n()（）]*)[)）])',r'删除6:<u>\1</u>'],#改
```

### 5.后缀字符删除的补充

例如：

两种病变均可出现乳头溢液。口
属良性肿瘤。二

补充到删除12：

```
[r'([。] *)(_[A-Za-z0-9]_\**|[口二]\**)(\n|$)',r'\1删除12:<u>\2</u>\3'],#后缀字母，改
```

### 6.章节前缀字符删除

例如：

```
_海_ 第十三章脑 缩
```

增加到删除21：

```
[r'(_[\u4e00-\u9fa5]_ *)(第[0-9一-十四]+[章节].*)',r'删除21:<u>\1</u>\2'],
```

### 7.多余标点删除

例如：

一、、（多余标点）硬膜外积脓

脑内片状或条带状T加权像低信号， _，_ （多余标点）T加权像高信号区。

增加到删除20：

```
[r'((、){2,}|(?:[ _]*(，)[ _]*){2,}|(?:[ _]*(\.)[ _]*){2,})',r'\2\3\4删除20:<u>\2\3\4</u>'],
```

### 8.图片描述补充删除

例如：

图6-1 前交通动脉瘤破裂出血

SE序列轴位T，(a)和T：(b)加权像，示前交通动脉位置亚急性血肿，中心区T，呈高信号，T：呈低信号，为正铁血红蛋白期，红细胞膜完整.（图片描述）

补充到删除4：

```
[r'(\n|^)(\** *[见续_]?[图] *\d+(?:[\–\-\—.]\d+)?.*)(\n+\**(?:SE序列).*)?',r'\1删除4:<u>\2\3</u>'],#删除图片索引，改
```
