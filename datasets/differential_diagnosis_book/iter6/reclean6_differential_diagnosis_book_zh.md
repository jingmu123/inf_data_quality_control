## reclean6_differential_diagnosis_book_zh

### 1.页码数字

例如：

_4_ 4.脑膜刺激征多明显。
_—_ 一、神经鞘瘤(neurilemoma or neurinoma)

在标题重复了数字的部分，增加删除23：

```
[r'(\**_[\d\—]+_)( [\d一-十四]+)(\\?[\.、])',r'\1删除23:<u>\2</u>\3'],
```

例如：

【发病原理】 在牙齿胚胎形成分化期，港釉器上皮由于某种作用而变性，牙胚内及周围组织发生炎症，是造成牙齿形态改变、发育异常的原因。所累6116及牙齿从—最为常见。这可能与以下621126因素有关：

属于个例，增加删除个例4：

```
[r'(所累|这可能与以下)(\d{3,})(及牙齿|因素有关：)',r'\1删除个例4:<u>\2</u>\3'],
```



### 2.多余标点

例如：

界面消失呈巨脑回(公)和多小脑回畸形(》)；

中线前部脂肪密度肿块伴钙化()，

出现空的括号内容以及多余的其余标点，增加删除24：

```
[r'([(（][ 》]*[）)])',r'删除24:<u>\1</u>'],#新
```

例如：

钙化在T?加权像也呈低信号（？为多余标点）

出现次数少，并且没有非常泛化的特征，增加删除个例5：

```
[r'(T)(\?)(加权像)',r'\1删除个例5:<u>\2</u>\3'],
```

### 3.错误删除

例如：

删除6:<u>（参考上文形态学分类）。要确诊某些贫血病例的病因，有时尚需沿着这条线索有选择地作一些特殊的血液学检查（删除8:<u>详见本章下文</u>）</u>。

删除的时候从上一个括号的左括号删除到了下一个括号的右括号了，之前是因为出现了括号中的括号内容才放开了限制，现在调整删除6：

```
[r'([（(]+ *(?:[参详][见考][^\n()（）]*[章节] *|[^\n()（）]*[参详][见考](?:上文|本章|书目)([^\n()（）](?:[\(（][^\n()（）]*[）\)])?)*|图示[^\n()（）]*|[见续]?[图表]\d+[\–\-\—.]\d+[^\n()（）]*|[^\n()（）]*\d{4}[，,;；：:][^\n()（）]*)[)）])',r'删除6:<u>\1</u>'],#改
```

例如：

删除10:<u>3.CV2</u>

误删了序号类的小标题，修改删除10：

```
[r'(\n|^)(\**[A-Za-z ·.。_（）()\[\]\\●■][A-Za-z0-9 ·.。_（）()\[\]\\●■]*\**|\**[0-9]+[A-Za-z0-9 ·。_（）()\[\]\\●■]*\**)(\n|$)',r'\1删除10:<u>\2</u>\3'],#字母符号句子，改
```

### 5.语义不完整

例如：

脑梅毒性脑梗塞带与药物性血管炎、自身免疫性血管炎所致的脑梗塞相鉴别。梅

```
[r'(。)( *[\u4e00-\u9fa5] *)(\n|$)',r'\1删除22:<u>\2</u>\3']
```
