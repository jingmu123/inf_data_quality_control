## reclean4_differential_diagnosis_book_zh

### 1.错误删除

删除15和删除8的边界没有设置好，导致误删了一部分内容

例如：

```
缺血性结肠炎是缺血性肠病删除6:<u>（删除8:<u>参见第71节）</u>中最常见的一种类型，......。</u>

```

删除8是删除整小句的参考内容，开头内容不可以出现句号以及左括号，在后续内容上漏掉了也不能出现右括号的限制，限制补充到删除8：

```
[r'([^\n(（。，；]*(?:参?见|参考|如|参阅|见)(?:[图表第]\d+|本)(?:[\–\-\—.]\d+[^\n）)。]*|[章节][^\n）)。]*))',r'删除8:<u>\1</u>'],#整句图片索引
```

例如：

```
第6节删除15:<u> _中_ </u>毒
```

修改范围成只找单独一行出现的在下划线中的文字，补充到删除15：

```
[r'(\n|^)(( *_[\u4e00-\u9fa5■●]+_[ ●■]*)+)(\n|$)',r'\1删除15:<u>\2</u>\3'],
```

### 2.页码数字补充

例如：

2.原因 因为层面的选择是根据不同的频率，所以也会受到化学位移的影响。 _4_

补充到后缀内容删除12：

```
[r'([。] *)(_[A-Za-z0-9]_)',r'\1删除12:<u>\2</u>'],#后缀字母
```

3.多余标点补充

例如：

...。（单独一行出现）

补充到删除字母符号句子的正则删除10：

```
[r'(\n|^)(\**[A-Za-z ·.。_0-9（）()\[\]\\●■]+\**)(\n|$)',r'\1删除10:<u>\2</u>\3'],#字母符号句子
```

例如：

、（多余符号）艾滋病脑炎 (HIV encephalitis)

增加删除17：

```
[r'(\n|^)( *[、])(.+)',r'\1删除17:<u>\2</u>\3']
```

### 4.参考文献标题遗漏

例如：

第十四章 肺部弥漫性病变/参考文献（遗漏）

参考文献

1.Fishmam AP.Fislman's Pulmonary Disease and Disordors.第3版.西安：世界图书出版公司，1998

2.侯显明，于润江.间质性肺病学.北京：人民卫生出版社，2003

3.周燕发.胸部X线、CT、MRI诊断学，北京：科学出版社，1999

4.崔祥出.实用肺脏病学，上海：上海科学技术出版社，1991

因为正则中的中文一到十的正则（一-十）不包括四，现在补充字符到删除3：

```
[r'(\n|^)((?:# *第[0-9一-十四]+章.*参考文献\n*|参考文献(?:\n-+)?)+((?:\n+[*_]*\d+[.,，、\\]?.*)|(?:\n+.*\d{4}.*)|(?:\n+第[0-9一-十四]+[章节].*)|(?:\n+(少尿或无尿|多　尿|血 尿|血红蛋白尿|脓 尿|乳 糜 尿)))+)',r'\1删除3:<u>\2</u>'],
```

### 7.多余换行补充

对非序号括号的多余换行补充，例如：

重量渗模浓度=2(Na\*mmol/L)+血糖 mmol/L+BUN mmol/L 删除换行1: \=2(Na\* meg/L)+(血糖 mg/dl)/18+(BUN mg/dl)/2.8 （多余换行）

(1mOsm 葡萄糖等于 180mg/L，1mOsm 尿素氮等于28mg/L)。



对非序号的数字多余换行补充（补充正则上数字后面的符号），例如：

蝶鞍扩大，鞍内高信号椭圆形肿块，突向鞍上，大小约（多余换行）

2.0×（补充乘号）1.2>1.2cm。彰底受压交博，视交叉上举 删除换行1: 脉。T加权像、、T：加权像可见流空的颈内动脉周围软组织块影。良性垂体瘤也可侵犯破坏蝶窦、斜坡的骨质。

