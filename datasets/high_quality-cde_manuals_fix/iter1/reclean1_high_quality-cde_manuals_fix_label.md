## reclean1_high_quality-cde_manuals_fix_label

### 1.特殊符号删除

例如：

```
†‡
```

增加删除符号：

```
[r'([†‡])',r'删除符号:<u>\1</u>'],
```

### 2.页码

删除

例如：

第11页/共11页

增加删除1：

```
[r'(\n|^)([ \t]*第 *[0-9]+ *页[/ ，]共 *[0-9]+ *页)',r'\1删除1:<u>\2</u>'],#页码
```

### 3.页尾无关数字的删除

例如：

```
3
5
21 of 21（只出现在每一天的最末尾，联系上文，是无关数字）
```

增加删除2：

```
[r'((?:[0-9]+ *(?:of [0-9]+)?\n*)+)($)',r'删除2:<u>\1</u>\2'],#页尾无关数字
```

### 4.年份删除

例如：

2009.05.19
2011.06.01
 2012.9.26
 2013.2.19
 2013.8.1

增加删除3：

```
[r'(\n|^)( ?\d{4}\.\d{1,2}\.\d{1,2})',r'删除3:<u>\1</u>\2'],#年份
```

### 5.图片索引删除

#### 5.1例如：

```
图1.生存曲线：Cc vs Tc (协作组研究)
```

增加删除4：

```
[r'(\n|^)( *[见续_]?[图] *\d+([\–\-\—.]\d+)?.*)',r'\1删除4:<u>\2</u>'],#删除图片索引，
```

#### 5.2例如：

（图1）

增加删除5：

```
[r'([(（]图\d+[）)])',r'删除5:<u>\1</u>'],
```

### 6.语义不完整

语义不完整是由于标题换行对上一段文本最后一个字符的判断时，正则失误把最后一个字符吞掉了。

调整标题换行为：

```
[r'([^\n])(\n)([# ]*【[^\n【】]*】 *)',r'\1\n\n\3'],
```

### 7.多余换行

初次清洗对序号内容增加换行时导致了出现部分的多余换行，例如

有双侧或单侧肾动脉狭窄的患者（见

（多余换行）2.重要的基本注意事项）。

表

多余换行2.在18项临床研究的汇总分析中，发生≥1%患者中的精神科不良事件

现在在对序号内容增加换行调整，调整为

```
[r'([^\n0-9A-Z表I@见\(（：] ?)(\d+[．.、][^0-9%].*)',R'\1\n增加换行1：\2'],
```
