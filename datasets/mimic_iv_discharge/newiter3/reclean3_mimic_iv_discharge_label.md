## reclean3_mimic_iv_discharge_label

### 1.大 小写之间多余换行（补充）

删除符号限制：>
增加连接符：&
允许句子开头有多个空格

```
(\n|^)( *(?:[^\n•●©· ]{1,} +){5,}[^\n ]*[A-Z] *[-&]* *)(\n+)( *[-&]* *[a-z，,0-9’;)/][^.][^#\n•●©·:：.]+(?:(?:\d[:：]\d)*[^\n•●©·])*(?:\n|$))
```

### 2.小 大写之间多于换行（补充）

删除符号限制：>
增加上一段文本连接符：&*#
对上一段最后一个字符限制，不能是冒号

```
(\n|^)( *(?:[^\n•●© ]{1,} +){5,}[^\n ]*[a-z，,0-9’;(/%\-+] *[-&*#]* *)(\n+)( *[A-Z][^. ][^#\n•●©·:： ]*(?:(?: (?:(?:\d[:：]\d)*[^\n•●©·])*[^\n:：][^\n:：](?:\n|$))|(?:\n|$)))
```

### 3.大写 大写之间多余换行（补充）

删除符号限制：-，只有第一个单词不可以出现这个符号
对带句号的短句子结尾加上限制，后面是换行符或者尾部

```
(\n|^)( ?(?:[^\n•●© ]{1,} +){5,}[^\n]+[A-Z] *)(\n+)( *[A-Z][^\n\. ]*[^:：\-] +((?:[^\n•●©:： ]{1,} +){5,}.*)|(.*\. *(\n|$)))*
```

### 4.填空位置多余换行（补充）

例如：
WBC 5.5 w/ normal diff, Hgb 11.2, plts 216, BUN/Cr ___ 
(baseline Cr 1.5), Ca ___, Mg 1.2, Lactate 1.6.  UA was normal. 
可以连接非序号的括号内容
例如：
 by mouth every ___ 
hours as needed Disp #*30 Tablet Refills:*0
第一个单词后不能出现冒号，其他地方可以
增加连接符：；

```
((?:[a-zá，,;]|[DM]r.)[_ ]*(?:_)+[ -+]*)(\n+)( *(?:(?:[,，a-zA-Z‘)."“][^\n. ][^ \n:：]*( .*)?)|(?:[(（].{3,}[）)].*)))(?:\n|$)
((?:[A-Z，,;]|[DM]r.)[_ ]*(?:_)+[ -+]*)(\n+)( *(?:(?:[,，a-z‘)."“][^\n. ][^ \n:：]*( .*)?)|(?:[(（].{3,}[）)].*)))(?:\n)
```

### 5.小写 小写之间的多余换行（补充）

补充连接符："

```
([a-z，,0-9’;()/] *(?:>|<|\+|\–|%|\'|≥|=|≤|-|&|~|")* *)(\n+(?: *\n)?)( *(?:>|<|\+|:|%|\'|≥|=|≤|&|~|")* *(["“,，./a-z‘)][^.]|\$?\d+[^.][^.\\])|\(.{3,}\))
```

### 6.非序号数字开头存在多余换行（修改）

之前对数字后有逗号和单位的情况增加删除换行了，但是还是有一部分没有这些特征的存在多余换行，发现这个任务好像不存在  数字.数字 格式的标题，现在对这类统一删除换行，例如：
Initial vital signs were notable for a BP of 118/80, temperature
98.7 and HR 9799% on room air.

```
([A-Za-z，,0-9’;()/] *(?:>|<|\+|\–|%|\'|≥|=|≤|-|&)* *)(\n+(?: *\n)?)( *(?:>|<|\+|:|%|\'|≥|=|≤|&|~)* *(?:(?:\$?\d+\.\d+) *))
```

### 7.特殊格式的多余换行

例如：

- Stopped Meds: verapamil, hydrochlorothiazide, lisinopril

- Changed Meds: 
  （）FOLLOW-UP 

- Follow up: PCP ___ ___ days  删除换行4 OTHER ISSUES: 

  

___ 11:24AM BLOOD Type-CENTRAL VE Temp-36.3 Rates-20/ Tidal 
___ 03:25AM BLOOD ___ pO2-41* pCO2-32* pH-7.48* 
（多余换行）calTCO2-25 Base XS-0
___ 01:34PM BLOOD Lactate-1.1
因为这类文本的格式非常多变，长度也不长，所以如果用其他通用的删除换行去增加这类情况的话就会导致很多缺少换行，现在单独拿出来处理

```
(\n|^)( *(?:-|___)[^\n-].*)(\n)( *(?:-|___)[^\n-].*)(\n)([^\d\n\-\_][^\n\-\_]+(?:[^ \n]-[^ \n][^\n-]*)*)(\n)( *(?:-|___)[^\n-].*)
```
